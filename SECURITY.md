# Security

JT Technology takes security bugs seriously.

## Reporting a vulnerability

Do not open a public issue with vulnerability details.

- Preferred: GitHub private vulnerability reporting on this repository (the Security tab, Report a vulnerability).
- Alternative: justhinktechnology@gmail.com.

## What to expect

- Acknowledgement within 3 business days.
- Updates as we assess and fix.
- A reasonable window for remediation before any public disclosure.
