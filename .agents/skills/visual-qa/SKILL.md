# Skill — JTT Visual QA

## Purpose
Review the homepage as a complete visual system rather than checking isolated components.

## Load when
- reviewing a major UI change
- comparing production against the prototype
- preparing release

## Review order
1. Overall composition
2. Typography
3. Spacing/rhythm
4. Navigation
5. Hero
6. Section transitions
7. Services/Process
8. Cases
9. Vendono
10. Why JTT
11. Team
12. Contact
13. Footer
14. Mobile

## Prototype-specific checks
- Header has only Services, Products, Cases, About + Get in touch.
- Hero has Start a project + Our work.
- Positioning replaces the four removed standalone sections.
- Only one five-step process exists.
- Integrations copy does not overlap its description.
- Cases do not contain "INTEORATIONS".
- Vendono has mockup + Request access.
- Why JTT uses 3–4 concrete differentiators.
- Team includes both partners with photo, role and one-line description.
- Contact includes short form, email and WhatsApp.
- Closing CTA does not contain "View our services".
- Figma Make badge is absent.

## Done when
The page reads as one intentional experience and no prototype artifact remains.
