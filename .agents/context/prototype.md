# JTT Homepage — Prototype Contract

Reference prototype:
https://done-chunk-85975887.figma.site/

The prototype is the visual/structural reference for the first production implementation. The requirements below are the explicit product direction for the prototype-to-production transition.

## Required homepage structure

1. Header
   - JTT logo
   - compact navigation: Services, Products, Cases, About
   - one primary header action: Get in touch
   - no Contact navigation item
   - no Culture navigation item

2. Hero
   - current approved headline
   - current subtitle
   - two CTAs
   - primary: Start a project
   - secondary: Our work

3. Positioning
   - short section
   - consolidate the strongest ideas from the previous §01 Statement, §02 About, §09 Mission and §10 Manifesto
   - do not reproduce those four sections independently
   - the manifesto may survive as a single line immediately before the final CTA

4. Services
   - four categories
   - category tags
   - correct the Integrations copy so the label does not collide with/invade the description

5. Process
   - exactly one five-step process
   - place directly after Services
   - remove the duplicated process version

6. Cases
   - each project should show verified project result numbers when those numbers are actually available
   - optionally show a verified client quote
   - fix the typo "INTEORATIONS"
   - never invent metrics or quotes

7. Products
   - Vendono
   - premium product presentation
   - mockup
   - Request access CTA

8. Why JTT
   - three or four concrete differentiators
   - replace the generic six "non-negotiables" and five generic values
   - only use differentiators that are supported by JTT's actual positioning/capabilities

9. Team
   - photo of both partners
   - role
   - one concise line about each person
   - culture content may be represented here rather than as a separate navigation item/section

10. Contact
   - short form
   - email
   - WhatsApp

11. Footer
   - navigation
   - location
   - same contact channels

## Explicit removals

Remove as standalone sections:
- §01 Statement
- §02 About
- §09 Mission
- §10 Manifesto

Remove:
- duplicated process
- §06 Engineering with six generic non-negotiables
- §08 with five generic values
- Contact from navigation
- Culture from navigation when culture is integrated with Team
- secondary closing CTA "View our services"
- "Created with Figma Make" prototype badge

## Closing CTA

Primary closing action remains contact/project-oriented.

The old secondary "View our services" should become an alternate contact channel such as WhatsApp or email.

## Production rule

The prototype is a reference, not permission to copy implementation artifacts. Rebuild the experience with the project's Next.js architecture, semantic HTML, Tailwind/shadcn conventions, Motion/GSAP ownership rules and performance/accessibility standards.
