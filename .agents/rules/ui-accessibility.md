# Accessibility Rules

- semantic landmarks and logical heading hierarchy
- keyboard navigation
- visible focus
- meaningful labels
- sufficient contrast
- correct image alt text
- no keyboard traps
- reduced-motion support
- hover must never be the only interaction path

Menus/dialogs must preserve focus behavior and expose state appropriately.
