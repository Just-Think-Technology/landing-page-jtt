# JTT Design System

Feel: technical, premium, precise, cinematic, editorial, ambitious, modern and restrained.

Palette:
`#050505` background
`#0D0D0D` surface
`#141414` surface-2
`#FFFFFF` foreground
`#8A8A8A` muted
`#242424` border
`#4F7CFF` accent

Typography:
- display: Manrope / Geist / Inter Tight
- body: Inter
- technical: Geist Mono / IBM Plex Mono

Desktop baseline: 12 columns, 24px gutters, ~64px outer margins, max content around 1440px.
Mobile baseline: ~20px horizontal padding.
Tablet baseline: ~32px.

Prefer strong typography, negative space, controlled density and editorial composition. Avoid repetitive cards, excessive rounded containers, visual noise and decorative gradients everywhere.
