# Workflow — Dependency Change

1. Inspect `package.json`.
2. Search the codebase for an existing capability.
3. Check whether Next.js, React, Tailwind, shadcn/ui, Motion or GSAP already solves it.
4. Evaluate client bundle and maintenance cost.
5. Check current package compatibility.
6. Add only when justified.
7. Run relevant checks.
8. Document architectural dependencies when appropriate.
