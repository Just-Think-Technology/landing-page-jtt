# Workflow — New Section

1. Define the section's job in the narrative.
2. Identify the user question it answers.
3. Confirm factual content.
4. Define desktop and mobile composition.
5. Decide whether interaction is necessary.
6. Choose the simplest animation mechanism.
7. Implement semantic structure.
8. Add responsive and accessibility behavior.
9. Test reduced motion.
10. Run relevant checks.
11. Review the section in the full-page narrative.

A section should not exist only because it looks impressive.
