# JTT Agent System

`.agents/` contains detailed, version-controlled guidance for coding agents.

Principles:
- progressive disclosure
- repository-specific rules
- single source of truth
- small, reviewable documents
- no duplicated prompts

Structure:

```text
.agents/
├── README.md
├── rules/
├── workflows/
├── checklists/
├── context/
└── skills/
```

Read `AGENTS.md` first, then only the documents relevant to the current task.
